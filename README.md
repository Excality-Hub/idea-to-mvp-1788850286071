# App

Generated by idea-to-mvp. Run `npm install && npm start`.

## Todo API

In-memory todo list (no persistence across restarts).

### `GET /todos`

Returns all todos.

```sh
curl http://localhost:3000/todos
```

### `POST /todos`

Creates a todo. Body: `{ "title": string }`.

```sh
curl -X POST http://localhost:3000/todos \
  -H "Content-Type: application/json" \
  -d '{"title": "Buy milk"}'
```

### `POST /todos/:id/done`

Marks a todo as done.

```sh
curl -X POST http://localhost:3000/todos/1/done
```
